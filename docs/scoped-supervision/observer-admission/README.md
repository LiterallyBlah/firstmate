## Observer contract

`session.mjs` creates a fresh case ID and worker-instance ID, local AsyncLocalStorage context, counters, output identity and restoration list. Only the original callback's async context records method spans. Other work delegates unchanged. Disposal restores wrappers, disables recording and retains pending rows as unfinished. Late completions do not rewrite those rows or enter another session. Reuse is an observer error and delegates the original work without reactivating the session.

At most 8,000 records/restorations, 1,024 characters per data field, eight error excerpts and 128 pending ancestor chains of depth 32 are retained. Record loss, field/ancestry truncation and sink errors are explicit; an incomplete receipt is an **observer failure**, never a product pass/failure. A sink is synchronous best-effort; async sinks are unsupported and reported. A failed sink cannot durably report its own failure to that sink: the caller/external witness must retain the returned status. No new retry is performed.

Delegation preserves the receiver, arguments, values, thrown error and original native promise identity. FileHandle instrumentation returns the same handle. Side promise continuations, rejection handlers, method shadowing, tracing and AsyncLocalStorage still perturb execution. Recorded inclusive times are observations of JavaScript work, not native I/O measurements, kernel-stall proofs or a historical cause. Unsupported arbitrary thenables are outside this native-promise observer contract.

`containment.mjs` is an external parent-clock witness for **one dedicated owned child**, with a bounded event/output receipt. It records case entry, heartbeats, external deadline, kill request and close confirmation separately. A successful kill request alone never admits a next case. Unconfirmed termination keeps admission closed; receipt values cannot later be rewritten by a late event. The synthetic delayed-thread and nonsettling controls are not OS probe or filesystem qualification. This helper does not prove descendant termination, authenticate IPC, implement fencing, or justify killing any unrelated process. A stalled/unresponsive parent also remains outside its timing guarantee.
