## Preserved boundaries

Reoffering a page transfers informational facts, not authority to repeat an old effect. Existing
manual replacement, old-actor quiescence, binding/checkpoint verification, operation holds and
final gateway authority checks remain required. Already handled facts never reoffer. The old
offer remains retired history; the contiguous handling watermark remains S02's result.

An observation deadline means unknown. It does not cancel a receiver operation, prove death,
refund spend, resend a prompt, or authorize takeover. The original pending read remains attached
to its subject; a late effect receipt can settle only the original intent. Repeated recovery
passes share that pending read. The internal default read deadline is five seconds; isolated
fixtures can override it. This introduces no recurring timer or scheduling mechanism.

The existing shared journal, S02 source gaps/mailboxes and S04 continuation projection remain
authoritative. The native ingress method can restrict recovery to a scope's registered worker
identities. No routine summary forwarding, duplicate Needs-you item, new engine, watch or journal
is introduced. The receiver contract and activation gates in [S04.md](S04.md) remain unchanged.
